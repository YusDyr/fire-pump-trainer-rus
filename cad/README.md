# 3D-модель ступени нормального давления НЦПК-40/100-4/400

Модель снята с рис. 2 РЭ насоса (продольный разрез ступени НД). Масштаб 3,82 пикс/мм определён по подшипнику 309
(D 100, d 45, B 25 мм) и проверен по подшипникам 307 и 7000108. Точность размеров около ±1 мм.

## Файлы (`model/`)

| Файл | Что это |
|---|---|
| `NCPK_stupen_ND.FCStd` | FreeCAD 1.0: 23 параметрических тела (эскиз полупрофиля + вращение), лопатки, сетка, диски муфты, радиальные детали, подложка рис. 2 в масштабе 1:1 |
| `NCPK_stupen_ND_razrez.FCStd` | Та же модель с вырезанной четвертью (y<0, z>0) — видно устройство |
| `*.step` | Для любой CAD-системы, с цветами |
| `*.glb` | Для Blender и просмотрщиков (метры, ось Y вверх) |
| `NCPK_stupen_ND_profili.dxf` | 2D: полупрофили всех деталей, по слою на деталь, номера позиций по рис. 2 |

Ось вала — глобальная X, x = 0 — торец вала со стороны полумуфты. Профили лежат в плоскости XZ.

## Что упрощено

- Корпус и улитка сделаны телом вращения; настоящий спиральный отвод и масляный картер внизу корпуса несимметричны.
- Лопатки: 6 шт., логарифмическая спираль 24°. На чертеже их форма и число не видны.
- Механизм включения муфты ступени ВД показан осью вилки, без рычагов. Кран сливной 16, шпильки и прилив корпуса не моделировались.

## Как пересобрать (`src/`)

`parts.py` — профили деталей (x в пикселях скана, r в мм). Поправьте точки и запустите во FreeCAD 1.0:

```
freecad src/build_fc.py            # NCPK_stupen_ND.FCStd, .step, .glb в src/out
NCPK_CUT=1 freecad src/build_fc.py # вариант с разрезом
python3 src/make_dxf.py            # DXF (нужен ezdxf)
```
