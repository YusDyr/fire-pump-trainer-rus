# Тренажёр пожарного насоса НЦПК-40/100-4/400М-В1У

Учебный эмулятор насосной установки автоцистерны **АЦ 1,6-40/4 на шасси ГАЗон NEXT (C41R33)**, ДПК «Экстремум».

**▶ Открыть в браузере:** https://yusdyr.github.io/fire-pump-trainer-rus/

**📱 Приложение для Android:** [последняя версия](https://github.com/YusDyr/fire-pump-trainer-rus/releases/latest) · [NCPK-emulator.apk](NCPK-emulator.apk) — работает без интернета.

**📋 Что нового:** [CHANGELOG.md](CHANGELOG.md) · [все версии](https://github.com/YusDyr/fire-pump-trainer-rus/releases)

## Что умеет
- Насосный отсек по фотографиям машины: вентили, краны, дозатор, БУК-02, пульт АЦ — всё нажимается и крутится, манометры показывают реальные значения
- Задания: работа от цистерны, гидранта, водоёма, перекачка, катушка ВД, тактика с разветвлением, заполнение цистерны, проверка на «сухой вакуум»
- Пошаговые уроки, режим экзамена, оценка оператора
- Неисправности из РЭ насоса и РЭ АЦ с диагностикой
- Режим «Лето / Зима» с зимними операциями по РЭ
- Анимированная схема потоков с управлением
- Звуки, вибрация, сохранение прогресса

## Источники
РЭ насоса НЦПК-40/100-4/400 (КШИН.062223.015 РЭ), РЭ автоцистерны АЦ 1,6-40/4, паспорт насоса, протокол приёмо-сдаточных испытаний.

Учебное пособие, не заменяет руководство по эксплуатации и практические занятия.
