# Ролики потоков воды (Blender)

Сцена строится из 3D-модели `cad/model/NCPK_M_V1U.glb` скриптом `water_scene.py` (Blender 5.2).
Вода показана схематично: частицы по линиям потоков (Geometry Nodes, группа «Поток»), заполненные участки — полупрозрачная «жила».
Четыре сценария в одном таймлайне (маркеры), каждый рендерится отдельным роликом:

| Ролик | Сценарий |
|---|---|
| `NCPK_vodoyom.mp4` | Забор из открытого водоёма: вакуумный затвор, агрегат, заполнение, подача |
| `NCPK_cisterna_gidrant.mp4` | Подача из цистерны, работа от гидранта, заполнение цистерны через вентиль DN80 |
| `NCPK_sliv_produvka.mp4` | Слив (кнопка «СЛИВ»), продувка сжатым воздухом, короткие включения вакуумной системы |
| `NCPK_VD_pena.mp4` | Ступень ВД (муфта, ремень, перепуск, кран ВД), пеносмеситель и дозатор |

Сборка и рендер:

```
# в Blender (Scripting): папка с NCPK_M_V1U.glb
DIR = '/путь/к/папке'; exec(open(DIR + '/water_scene.py', encoding='utf-8').read())   # → NCPK_potoki.blend
# фоном, 1280×720, все сценарии (или номера: -- 100 1 3)
blender -b NCPK_potoki.blend --python render_bg.py -- 100
```

Ролики кладутся в `video/` рядом с .blend; на сайт — в `emulator/video/` (сжатие: `ffmpeg -crf 28 -movflags +faststart`).
`rt.py` и `sh.py` — пробные кадры по шагам и по ракурсам камеры.

Тексты шагов и последовательность действий — по РЭ насоса М-В1У (2025) и урокам эмулятора; правятся в `water_scene.py`
(функции `step(...)` в разделах S1–S4).
