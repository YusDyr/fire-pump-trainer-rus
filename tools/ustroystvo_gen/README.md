# Подготовка данных для разрезов на странице «Устройство насоса»

Скрипты, которыми сделаны `src/ustroystvo/{nd,hp}_parts.webp`, `hp_mask.webp` и пути воды в `{nd,hp}_data.json`.
Пути к исходникам (сканы рис. 2 и 5, сечения модели `geo.json`/`hpsec.json`, маски воды) заданы в начале скриптов —
это рабочие файлы, в репозиторий они не входят.

1. `regions.py` — сечения 3D-модели (плоскость оси НД и плоскость А-А ступени ВД) растеризуются в карту номеров позиций.
2. `snap2.py` — чертёж делится на области, ограниченные контурными (толстыми) линиями; штриховка и выноски тонкие и не мешают.
   Каждая область получает номер детали голосованием по карте из п. 1, поэтому деталь закрашивается целиком и по линиям чертежа.
3. `snap.py` — запасной вариант для мест, где контур разомкнут: голосование по мелким белым участкам между штрихами.
4. `route.py` — пути частиц воды прокладываются по маске проточной части (кратчайший путь с притяжением к середине канала).
5. `assets2.py` — всё вместе: ручные дополнения (корпуса, сетка 13 по дуге), вода в каналах колёс ВД и внутри сетки, опорные точки подписей.
